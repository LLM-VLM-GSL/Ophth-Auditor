    Working through the cases

    Answer with the mouse or the number keys: 1–7 answer the highlighted question and move on, ↑ ↓ change the question, ← → change the case, Space plays the audio, ? lists all keys. A complete case opens the next one by itself. Guide, at the top, has the full rubric.

      The rubric

      Saving and sending your work

      Every answer is saved automatically in this browser (and on this computer's audit server, because the page was opened through serve.py). You can close the page and continue later in the same browser by typing the same name. When you finish, or at the end of each sitting, click Export JSON and send the downloaded file to the study team. Load annotations merges a file exported earlier (for example, to move to another computer); for each case the newer annotation wins.

      Please do not share, copy or upload the images or texts.
